# 标签与边界参考（初稿）

本表来自一次UBM人工修订示范。使用前与项目最新标准核对；它不是完整解剖学标准，也不要求所有未来切面必须包含相同对象。

| 标签 | Labelme图形 | 本次示范的使用方式 |
|---|---|---|
| 角膜 | `polygon` | 内外边界围成闭合带状区域 |
| 巩膜左、巩膜右 | `polygon` | 按画面左右各标一个区域 |
| 虹膜左、虹膜右 | `polygon` | 按画面左右各标一个区域 |
| 睫状突左、睫状突右 | `polygon` | 与睫状肌分别围成区域 |
| 睫状肌 | `polygon` | 两侧沿用同名标签，按空间位置区分 |
| 小梁网 | `circle` | 两侧沿用同名标签；两点分别表示圆心和圆周点 |
| 晶体表 | `linestrip` | 开放折线，不自动闭合成面 |

这里的“左/右”指画面侧方，与文件名中的患者左眼/右眼是不同概念。不得自动为同名`睫状肌`或`小梁网`添加左右后缀。若新协议另有规定，以新协议为准。出现“睫状突/睫状体”等用词冲突时，不静默视作同义标签。

在本次10图的最终保存结果中，每图有12个对象：9个多边形、2个圆和1条开放折线。这只是这批结果的盘点，不是未来每张图都应凑齐12个的门槛。

## 从修订图像直接观察到的范围变化

- **角膜**：初稿只标中央清晰段；人工结果延伸至两侧周边，内外边界分别贴合原图轮廓，两端与侧方巩膜分界相接。部分较低回声周边也被纳入。可沿外缘描到对侧、沿内缘返回闭合；不固定起点、方向或厚度。
- **巩膜**：角膜延伸后，靠内的截断位置、外缘和后下方范围也被重新检查。个别区域的人工轮廓包含内部暗区，不能简单将“白亮像素”当作组织定义。
- **睫状突与睫状肌**：本批新增睫状肌位于各侧巩膜下方并偏外，睫状突相对更靠内，邻近虹膜根部下方。各图的凹凸、细长末端和区域大小不同；这些位置描述只帮助复看本批示范，不能据此机械生成其他病例轮廓。
- **小梁网**：部分圆随重画的局部交界移动、变大或缩小，部分圆没有改动。不存在本轮已确认的固定圆半径、统一位移或与虹膜根部的固定距离。
- **晶体表及虹膜**：即使点数、整体范围都不变，也可能有多个顶点精修。应比较实际曲线，而非仅比较数量或包围框。

## 仍待专业标准补充

- 周边低回声段纳入的可执行判据、结构不可见时的处理及部分可见范围。
- 角膜/巩膜、虹膜根部及睫状突/睫状肌的精确解剖分界。
- 小梁网圆所指目标、定位依据与半径的统一约定。
- 睫状突与睫状体命名是否需要修订，及对应标签版本迁移方法。

上述未知不能由某张图的坐标、点数或操作顺序替代。收到新专业意见后更新对应条目，并保留仍适用的既有规范。
