# 标签与边界参考（初稿）

本参考结合2026-10-23及2026-10-25对同批UBM图像的人工修订。使用前与项目最新标准核对；它不是完整解剖学标准，也不要求所有未来切面必须包含相同对象。

| 标签 | Labelme图形 | 示范中的使用方式 |
|---|---|---|
| 角膜 | `polygon` | 内外边界围成闭合带状区域 |
| 巩膜左、巩膜右 | `polygon` | 按画面左右各标一个区域 |
| 虹膜左、虹膜右 | `polygon` | 按画面左右各标一个区域 |
| 睫状突左、睫状突右 | `polygon` | 与睫状肌分别围成区域 |
| 睫状肌 | `polygon` | 两侧沿用同名标签，按空间位置区分 |
| 小梁网 | `circle` | 两侧沿用同名标签；两点分别表示圆心和圆周点 |
| 晶体表 | `linestrip` | 开放折线，不自动闭合成面 |

这里的“左/右”指画面侧方，与文件名中的患者左眼/右眼是不同概念。不得自动为同名`睫状肌`或`小梁网`添加左右后缀。若新协议另有规定，以新协议为准。出现“睫状突/睫状体”等用词冲突时，不静默视作同义标签。

本批10图在两轮示范收尾时，每图均保存12个对象：9个多边形、2个圆和1条开放折线。这是本批结果的盘点，不是未来每张图都应凑齐12个的门槛，也不代表边界已通过专业审核。

## 逐结构学习结果

- **角膜**：早期修订曾将中央清晰段延伸至两侧周边；后续复核主要精修周边末端及邻接分界，部分回收、部分延长，已有可用的中央弧段可保留。检查内外边界围成的带状区域，不将“继续向外画”当作固定要求。部分低回声周边曾被纳入，但纳入判据仍需专业标准。
- **巩膜**：结合角膜末端重新核对交接及外侧、后下方范围。有些对象删除后重画，有些保留后修点；不少重画范围收紧，也有面积近似保留而边界改变的情况。不能规定统一缩小比例或统一重画。个别区域含内部暗区，不能只按白亮像素划分组织。
- **睫状突与睫状肌**：两类分别成面，保留各图的凹凸及细长末端。后续示范中既有睫状突收紧，也有局部扩大、横向变宽而纵向变窄，或本轮保持不动的情况。每侧独立判断。旧稿“睫状突更靠内、睫状肌更靠外”的描述不再作为通用定位规则；新示范有标签对应区域相对横向位置变化，需结合本图与专业确认，不能据此自动交换标签。
- **小梁网**：部分圆随局部交界移动、变大或缩小，部分没有改动。不存在示范已确认的固定半径、统一位移或与虹膜根部的固定距离。
- **晶体表及虹膜**：点数或整体范围不变时仍可能存在顶点精修。应比较实际曲线；本轮未改变只能记为未记录到几何修改，不能解释为专业认可。

局部修改后联动查看邻近结构，再回到整图核查两侧及整体轮廓。示范中还观察到用户调阅解剖示意图；这支持将示意图作为辅助核对，不足以推断用户未解释的具体医学判断。

## 这些变化不能成为固定模板

| 示例中出现的差异 | 可复用的处理原则 |
|---|---|
| 同一张图一侧修点、另一侧重画 | 按对象和可见边界分别判断 |
| 同类区域一侧收紧、另一侧局部扩大 | 不设统一缩放方向或比例 |
| 顶点数在不同修订中有增有减 | 顶点服从轮廓形态，不以数量评价质量 |
| 暂时删去多个面对象，之后全部补回 | 以最后保留结果判断，不能把中间缺项当作省略规则 |
| 标签选择中出现临时重复，随后纠正 | 核对最后标签与对应轮廓，不继承临时误选 |
| 整批回看时再微调一两个区域 | 收尾时重新核对各图最后保存状态 |

本表记录操作和几何差异，不把面积、顶点数、倍率、坐标或单图空间关系写成医学阈值。

## 仍待专业标准补充

- 周边低回声段纳入的可执行判据、结构不可见时的处理及部分可见范围。
- 角膜/巩膜、虹膜根部及睫状突/睫状肌的精确解剖分界。
- 睫状突与睫状肌标签和轮廓对应存疑时的确认方法。
- 小梁网圆所指目标、定位依据与半径的统一约定。
- 睫状突与睫状体命名是否需要修订，及对应标签版本迁移方法。

上述未知不能由某张图的坐标、点数或操作顺序替代。收到新专业意见后更新对应条目，并保留仍适用的既有规范。
