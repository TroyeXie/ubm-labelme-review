# 审核示范观察方法

## 不干扰用户操作

开始时说明将被动观察及本轮结束方式。用户操作期间不点击、输入、切换图片、调整缩放、保存或抢焦点；用户要求接管后再进入编辑模式。

使用当前可用的电脑操作能力读取Labelme。用户切到其他应用时，不操作或解读无关内容。若工具返回的截图与目标应用不符，该画面不能作为Labelme操作证据；可继续只读核对标注文件。看不到画面或观察中断时如实说明，不能用保存结果补造鼠标、按键或先后步骤。学习模式不自动导出操作截图；用户另有要求时再处理。

## 结合画面与稳定保存版本

- 开始前固定本轮最新基线，记录正在编辑的图像和实际文件关联。续轮应使用用户本轮修改前的版本，不能一直沿用最早AI初稿；原始图像及用户标注保持不动。
- 如需自动观察保存变化，只读取用户指定范围，读取成功且内容稳定后才建立快照；遇到JSON正在写入时跳过并重读，不干预软件保存。
- 只记录变化；连续观察需要时可在本地保存稳定快照、时间与摘要，以便辨认撤回、中间尝试及最后状态。不要为普通单次检查强制生成大批日志。
- 恢复观察时区分“已保存状态”和“实时看到的操作”。观察空档内只知道前后结果，不知道完整动作序列；恢复捕获时间也不能当作文件实际修改时间。
- 连续观察程序到期或重启时，确认前一程序结束再续接，避免两份程序同时记录；保留确实发生的观察间隔。

## 比较什么

按标签和空间位置对齐对象，特别注意双侧同名标签；数组次序不能决定左右。分别比较标签、图形类型、实际顶点、圆心/半径和图像关联。元数据变化与几何变化分开记录。注意用户切图后可能返回修订，以收尾时每张图最后稳定版本为准。

| 看到的事实 | 可以记录 | 不能直接推断 |
|---|---|---|
| 原对象逐点改变 | 局部精修，点数可能不变 | 用户使用了未看到的快捷键 |
| 删除后出现新轮廓 | 连续记录支持时为重画 | 中间缺项就是最终省略要求 |
| 新增后又删除 | 试画或中间状态已撤回 | 新增的区域应成为通用标签 |
| 暂时重复标签后又改名 | 标签纠正及最后对应关系 | 重复名称是新的项目规范 |
| 圆移动后恢复 | 最后保存状态及中间变化 | 固定位置或半径规则 |
| 某个对象没有变化 | 本轮未记录到几何修改 | 已审核认可或医学正确 |
| 保存对象数齐全 | 本项目清单的结构检查结果 | 所有边界贴合或专业审核通过 |
| 对照解剖示意图后继续编辑 | 调阅参考与继续编辑的先后事实 | 用户未说出的医学判断或删改原因 |

同点数不证明未重画，整体范围不变不证明未改动；必要时查连续记录。仅凭两个快照无法确定具体操作方式时，说“前后发生变化”，不补造过程。减少点数、缩小面积或轮廓更平滑本身都不是质量结论。

## 收尾与形成规则

用户结束示范后停止观察及后台记录；以最后稳定保存版本核对当前文件，避免漏掉结束前刚保存的修改。必要时分别核对原图未变、标注与最后快照一致。结论区分三类：

1. **已观察的操作**：例如局部放大、逐点精修、删除后重画、补画结构、对照参考及整图回看。
2. **可复用的项目参考**：需要多图一致的图像证据或用户明确解释，并标明适用范围；单侧或单图的处理作为局部示例保留。
3. **待确认的医学解释**：用户未说出的删改原因、模糊边界判据、标签与结构对应存疑处或专业认可状态。

保留简洁的项目学习记录，写清本轮基线、最后版本、变化依据及待补充事项。再次示范时先更新旧时点事实，不沿用已被后续补画、撤回或回看修点取代的状态。将临时尝试剔除出最终规则；不要将固定倍率、坐标、顶点数、对象顺序和本批数量泛化。

Skill更新仅带入通用、脱敏的规则。含患者身份的本地路径、图像及真实JSON不进入公开仓库；跨会话长期记忆更新另按用户明确要求处理。
