# UBM Labelme Review

**v0.2.0 · 初步Skill，持续完善中。**

帮助Codex依据项目标准检查、修订UBM标注，并观察和整理人工审核示范。经验来自2026-10-23及2026-10-25对同批10图的多轮修订；适用范围和待确认的专业边界已在参考文档中区分。本包不提供诊断，也不包含自动医学分割模型。

## 使用

将本目录作为一个完整Skill导入支持`SKILL.md`的客户端，保留`references`和`agents`目录。调用标识为`ubm-labelme-review`。

> 请使用 $ubm-labelme-review，依据我提供的最新标注标准检查现有UBM图像与Labelme标注，保留原图并在副本中完善。

或：

> 请使用 $ubm-labelme-review，观察我在Labelme里的审核修改，不代我点击；示范结束后整理可复用规则和待确认事项。

实际使用仍需本地原图、现有标注及项目最新标准。电脑操作能力由当前客户端提供；本包不自动安装Labelme、建立环境或变更系统配置。

- [审核示范观察方法](references/learning-from-review.md)：被动观察、本轮基线、过程与结果区分、整批回看后的版本核对。

本版补充逐对象选择修点或重画、角膜末端与邻近结构联动复看、睫状突每侧范围独立判断，以及整图回看后继续修点的处理。旧稿中的固定相对内外位置描述已收回为待专业确认的具体情形；不设统一缩小比例、顶点数量或12对象完成门槛。
